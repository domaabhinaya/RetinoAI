Build the complete FRONTEND SKELETON for a healthcare AI web application called "RetinoAI".

IMPORTANT:
Do NOT build the backend, database, real AI models, hardware integration, or real medical diagnosis yet.

The purpose of this task is to create a clean, professional, fully navigable frontend foundation that we will enhance later with Motion Primitives and additional functionality.

==================================================
PROJECT
==================================================

Application name:

RETINOAI

Main title:

AI-Assisted Diabetic Retinopathy Screening

Secondary title:

with Secondary Retinal & Optic-Disc Abnormality Screening

Tagline:

"Capture → Check → Detect → Explain → Track → Refer"

Safety principle:

"AI assists. Doctors decide."

This is an internal SIH 2026 hackathon prototype.

CURRENT PROTOTYPE SCOPE:

The prototype is SOFTWARE-FIRST and UPLOAD-FIRST.

Patients or healthcare workers can upload existing fundus/retinal photographs and available reports from a clinic or hospital.

We are NOT currently building the physical fundus imaging hardware.

Future hardware integration should only be represented as a planned/future feature.
